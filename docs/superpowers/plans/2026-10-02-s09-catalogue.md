# С09 — каталог: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking. Пользователь разрешил документы и реализацию автономно. Native backend/frontend boundaries, один финальный обзор всей ветки.

**Goal:** Управление версионируемыми тарифами и клиентский выбор точного предложения.

**Architecture:** PostgreSQL хранит stable plan UUID и immutable revisions; existing transaction/idempotency/role guards защищают редактор. Новый экран кабинета читает только текущие видимые предложения; платёжный поток следует в С10.

**Tech Stack:** Existing Go/Echo/pgx/sqlc, React-admin/React/TypeScript/Playwright; без новых зависимостей.

**Spec:** [С09](../specs/2026-10-02-s09-catalogue-design.md)

## Global Constraints

- devices1..10000, traffic_gb0..100000; profiles regular/euru/unlimited, unlimited скрыт и не покупается; traffic0 ≠ бессрочный срок.
- Положительные целые дни, полная матрица RUB/USD/XTR каждого объявленного периода, без повторов. Цены — десятичные строки целых minor units: RUB/USD2 знака, XTR0. Negative/overflow/nonfinite/fractional values отказали;0 сохранён.
- Не выдумывать коммерческие seed prices; hidden unlimited seed7devices/100GiB явно и идемпотентно.
- Уникальный devices среди active; последний visible plan не скрывается/архивируется; archived сохраняет все revisions.
- Live role/session actor, reason1..1000 безNUL, Origin/CSRF, bounded strict JSON, UUID Idempotency-Key, expected_revision.
- Native boundaries: backend owns API/schema/CLI/tests; frontend owns web; root docs/local commits/own Docker3X-UI3.7.0. Production/Happ/MacVPN/publication исключены.

## Review Focus

- Цены выше JS safe integer остаются точными строками: API roundtrip и browser display без Number(amount).
- Два параллельных архивирования не удаляют последний видимый план: реальная PG concurrency.
- Изменение устройств не захватывает занятый active slot; архивированный slot доступен новому плану, старый snapshot неизменен.
- Несовпадающие legacy IDs/devices и nonrepresentable float import не частично применяются и не округляются.
- Изменённая revision между открытием и сохранением формы оставляет reason/ошибку409 и предлагает перечитать; повтор ошибочного запроса не дублирует запись.
