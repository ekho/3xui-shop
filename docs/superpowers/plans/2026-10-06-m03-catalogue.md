# М03 — Catalogue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Native выбран владельцем; один свежий whole-branch reviewer в конце.

**Goal:** Закрыть существующий каталог за владельцем catalogue без изменения С09/С07/С08.

**Architecture:** Перенести прежние тела CRUD/import/seed и SQL в catalogue.
Переходный фасад переводит neutral DTO; app связывает публичный accounts owner.
Подписки читают снимки через caller transaction вместо чужого SQL.

**Tech Stack:** Существующие Go, pgx/sqlc, testing, PostgreSQL/Redis; без новых библиотек.

**Spec:** [М03](../specs/2026-10-06-m03-catalogue-design.md),
[С09](../specs/2026-10-02-s09-catalogue-design.md).

Baseline `c780927659f66b6ec8ae741cdddf310a7e464953`, ветка `feature/m03-catalogue`.
Повторное утверждение документов не требуется: автономное ведение уже разрешено.

## Global Constraints

- Один Go-процесс, один go.mod; HTTP/OpenAPI, web, schema и identifiers сохранены.
- catalogue не импортирует platform/store/wire/httpapi/app или чужую private реализацию.
- Neutral DTO сохраняют JSON tags/order; minor units — decimal strings, без float.
- Account/role → idempotency → catalogue locks; прежние hash/result и caller Tx сохранены.
- Один accounts owner и один catalogue owner в app; фасад только переводит типы.
- 3X-UI **3.7.0**, собственные DB/SMTP, simulated Telegram; Happ не переключать.
- PR #5 не переписывать; Conventional Commits и Co-Authored; PR только в `v2`.
- Локальная реализация, review, CI/release и production — отдельные результаты.

## Review Focus

1. Старый create/revise/archive replay с unsorted input и пробелами reason: тот же result без новой revision; Task 1.
2. Restricted/revoked actor после успешной операции: старый replay не обходит live authority; Task 1.
3. Caller transaction держит lock выбора цены до rollback, отменённый context не пишет revision; Task 2.
4. Смена/архивирование плана после назначения: старый snapshot/история не меняются; Task 2.
5. Nullable metadata, пустые arrays и цена выше JS safe integer: wire/DTO сохраняют результат; Task 1/3.
