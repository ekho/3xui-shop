# Предварительные релизы версии 2

Рабочие ветки текущего проекта создаются от актуальной `v2`, PR направляются в `v2`.
После каждого изменения `v2` workflow `V2 preview release` собирает и публикует
три Docker-образа для `linux/amd64` и `linux/arm64`:

| Компонент | Пакет GHCR |
| --- | --- |
| Бот | `ghcr.io/ekho/3xui-shop` |
| Backend | `ghcr.io/ekho/3xui-shop-backend` |
| Кабинет | `ghcr.io/ekho/3xui-shop-web` |

Каждый образ получает теги `2-dev`, `2.0.0-dev.N` и `2-<полный SHA коммита>`.
`N` — номер запуска workflow; повторный запуск той же сборки сохраняет номер.
После успешной публикации всех трёх образов создаются аннотированный git-тег
`2.0.0-dev.N` на исходном коммите и GitHub Release с признаком prerelease.
Описание содержит исходный коммит, адреса образов и изменения из GitHub.
Повторный запуск проверяет существующий тег и не перемещает его.

PR проверяет сборку всех трёх образов без публикации пакетов или релиза.
Публичные параметры кабинета задаются при запуске контейнера:
`TERMS_VERSION`, `PRIVACY_VERSION`, `TERMS_URL`, `PRIVACY_URL`, `SUPPORT_URL`.
Версии и HTTPS-адреса документов обязательны; адрес поддержки допускает HTTPS
или `mailto:`. Одинаковый образ можно использовать в разных окружениях.

Контейнер кабинета записывает эти публичные параметры в `/run/web-public/config.json`;
для read-only контейнера этот каталог монтируется как tmpfs с доступом пользователя
контейнера. Caddy обслуживает точный путь `/config.json` из `/run/web-public`
с `Cache-Control: no-store`; остальные маршруты сохраняют прежние правила.
Рабочая конфигурация приведена в `deploy/acceptance/compose.acceptance.yml`
и `deploy/acceptance/Caddyfile`. При отсутствующих или некорректных параметрах
кабинет сообщает об ошибке конфигурации и блокирует регистрацию.

Публикация версии 1 из `main` сохраняет прежний workflow.
Предварительные выпуски версии 2 не получают Docker-тег `latest` и не заменяют
последний стабильный GitHub Release. Развёртывание сервисов выполняется отдельно.

Проверка workflow:

```sh
go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12 .github/workflows/v2-release.yml
```
